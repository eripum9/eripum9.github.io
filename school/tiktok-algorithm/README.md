# The TikTok Algorithm

English school project page about how TikTok's For You recommendation system works and why short-video feeds can feel addictive.

## Recording support

- `speech-script.md` is the exact text to record.
- `speaker-view.html` displays the script as sentence IDs and can highlight sentences manually or with browser live speech recognition.
- `tools/align_transcript.py` can later match a transcript or Whisper-style JSON back to those sentence IDs.
